The backend-doctor skill performs a comprehensive, non-destructive diagnostic scan of a backend project across seven categories — project structure, database health, API compliance, security posture, test coverage, observability, and deployment readiness — checking each area against conventions.md rules and industry best practices, then produces a severity-ranked health report (critical/warning/info) with specific remediation steps, affected file paths, and an overall health score so developers can quickly identify and resolve the most impactful issues first.
