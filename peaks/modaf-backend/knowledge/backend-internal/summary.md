The backend-internal knowledge pack provides a complete reference library for building production-grade server-side systems. It contains 12 phase files that guide a project from initial bootstrap through deployment readiness, plus 20 internal reference documents covering API design, database patterns, authentication and authorization, service architecture, caching, queues, file storage, webhooks, rate limiting, logging, monitoring, testing strategies, security hardening, deployment, migrations, performance optimization, API versioning, environment configuration, and data serialization. Phase files define the sequential build lifecycle with prerequisites and quality gates; internal docs provide deep-dive guidance that can be loaded on demand based on the current task.
